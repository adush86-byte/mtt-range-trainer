iPhone: приложение адаптировано под Safari. Матрицу можно рисовать пальцем: коснись клетки или веди пальцем по диапазону.

Встроенные диапазоны — только демонстрационные. Для серьёзной тренировки внеси свои чарты/решения тренера. Приложение работает локально и хранит данные в браузере.

Рекомендуемый цикл

1. Создай диапазон → 2. Пройди 30–50 рук в «Тренировке в игре» → 3. Посмотри Heatmap → 4. Повтори только ошибки → 5. Воспроизведи диапазон целиком в «Тренажере диапазонов».
